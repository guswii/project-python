# XAUUSD Trading AI Agent — Training

Repo ini berisi **latihan/exercise** untuk melatih AI agent agar paham trading XAUUSD dengan metodologi **SMC (Smart Money Concepts)** + **ICT (Inner Circle Trader)**.

## 🎯 Untuk Siapa?

- AI agent yang masih "bodoh" soal trading
- Owner agent yang mau agent-nya jadi co-pilot trading
- Educator yang mau drill konsep SMC/ICT

## 📦 Isi

- **`TRAINING_EXERCISES.md`** — 8 modul × latihan, quiz, dan drill (15 minggu)
- **`QUICK_REFERENCE.md`** — Cheat sheet konsep + 12-point checklist

## 🚀 Cara Pakai

### Step 1: Clone / Download
```bash
git clone https://github.com/guswii/xauusd-trader-training.git
cd xauusd-trader-training
```

### Step 2: Kasih ke AI Agent
```bash
# Contoh untuk OpenCode/Hermes:
cp TRAINING_EXERCISES.md ~/.opencode/skills/xauusd-training/SKILL.md

# Atau untuk Claude Code:
cp TRAINING_EXERCISES.md ~/.claude/skills/xauusd-training/SKILL.md
```

### Step 3: Latih Bertahap
- **Minggu 1-2:** Modul 1 (SMC Vocabulary)
- **Minggu 3-4:** Modul 2 (ICT Framework)
- **Minggu 5-6:** Modul 3 (Multi-TF)
- ... dst sampai Modul 8

### Step 4: Test dengan Quiz
Setiap modul ada quiz. Pass = lanjut modul berikutnya.

## 📚 Yang Akan Dipelajari Agent

1. **SMC Vocabulary** — Liquidity, OB, FVG, BOS, CHoCH
2. **ICT Framework** — IPDA, AMD, Kill Zones, Silver Bullet
3. **Multi-Timeframe** — Daily → 4H → 1H → 15M cascade
4. **XAUUSD Specifics** — DXY correlation, volatility, news
5. **Validation & Risk** — 12-point checklist, R:R, position sizing
6. **Journaling** — Format jurnal, weekly review
7. **AI Co-Pilot** — Prompt engineering, refusal patterns
8. **Live Application** — Daily/weekly routine

## ⚠️ Disclaimer

Repo ini untuk **edukasi & training** saja. AI co-pilot BUKAN financial advisor. Trading = real loss bisa terjadi. User bertanggung jawab atas semua keputusan trading.
